# ほたる合わせ

夏の夜の森でひかりを合わせる、ワンボタンの音ゲー。https://kuuuu33.github.io/hotaru/

右から流れてくる蛍が、目印を通り抜ける瞬間にタップします。合わせた蛍は消えずに森へ残り、
続けるほど明滅のばらつきが縮んで、やがて森ぜんたいが同じ息で光りはじめます。

`index.html` 1枚と楽曲だけで動いています。ビルド作業はありません。
外部のライブラリもフォントも読み込まないので、機内モードでも遊べます。

## 構成

```
index.html          本体。HTML・CSS・JSが全部入り（約64KB）
song.m4a            楽曲。85秒、AAC 128kbps（約1.3MB）
assets/
  ogp.jpg             SNSシェア時のカード画像（1200×630）
  favicon-32.png / apple-touch-icon.png
```

## 遊びかた

画面のどこを叩いても構いません。**輪の中を蛍が通る瞬間**に合わせます。

- 内側の明るい円が「ぴたり」、外側の薄い円が「ちかい」の幅です。**円の大きさは判定の幅そのもの**を実寸で描いています
- 蛍の**色は次のリズムの予告**を兼ねています（濃い緑＝2拍にひとつ、黄緑＝拍のうえ、水色＝付点、淡黄＝八分、青緑＝細かい裏、金＝まれびと）
- 画面下の帯は命の光。合わせ続けると増え、外すと減ります
- タイトルの「ずかん・森」から、図鑑・育成・ステージを開けます

## 調整

音と絵がずれて感じるときは、右上の「◦」からデバッグパネルを開き、**「音と絵のずれ」**を動かしてください。
iOSのSafariは端末の出力遅延を正しく返さないため、自動では合わせきれません。
合わせた値は端末に保存されるので、次回から不要です。

叩き癖のずれは、夜の最初の24打で自動的に吸収されます。

## 楽曲について

BPM 91.000、Dドリアン（Dm と C を1小節ずつ）。テンポは全編で一定です。
譜面はこの曲の小節に合わせて組んでいます。曲を差し替える場合は、`SONG` の
`bpm` / `offset` / `bars` を実測して入れ直してください。

## つくりかた

時刻の基準は必ず `AudioContext.currentTime` で、`requestAnimationFrame` は描画にしか使っていません。
判定は指が触れた瞬間（`e.timeStamp`）を音の時計へ変換して行います。
遅延は「端末の出力遅延（描画と判定の両方をずらす）」と「叩き癖（判定だけをずらす）」に分けています。
ここを1つにまとめると、絵を見て叩く人に対して自動較正が発散します。
